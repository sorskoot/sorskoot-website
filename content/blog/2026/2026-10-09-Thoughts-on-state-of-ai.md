Personal thoughts on the current state of AI in softwaredevelopment. Where do I think the world is moving to.

#1
For a large part from a software architect and project management standpoint the changes in development of software using AI are not changing as much as people think at first. At the Rockstars Valley event I attended a presentation on agenic programming. At that point I realized that what the presenter was explaining on how to write specs and tasks is actually something we already _should_ do. For example, in the past I worked in a lot of teams where there was discussion that tasks should be defined better when doing scrum. Discussions about the need to improve requirements, about improving stories to help developers do their work more efficiently. Now the same discussions have shifted to writing the same in markdown files to help the AI do its work better. Same thing, different format. A scrum sprint was two weeks and now an agentic sprint is shortened to days or hours maybe. But to get a good result you need to write good specs and instructions for the AI. 

#2 
As a consultant type developer a set of skills and agents will be a large part of your toolset. 

#3
For the past 30+ years I imagined that one day, sometime in the far feature I can stop working and enjoy my pension. I imagened that at that time I didn't have to code for an employer anymore and could work on my own thing as much as I want. But this week I realized that that's not going to happen. Writing code will go away. It will become a craft similar to a miller grinding wheat using a windmill. It's only a living history to show people how it was done before machines took over the job.
